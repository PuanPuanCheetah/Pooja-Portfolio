How to deploy (GitHub web):
1. Unzip this file.
2. Open your repo on github.com > Add file > Upload files.
3. Drag everything from the unzipped folder (files AND folders) into the page.
   Same names replace the old files; folders keep their paths.
4. Click "Commit changes". Render redeploys automatically in 1 to 2 minutes.
5. Open https://poojajoshi-design.onrender.com and hard refresh (Cmd+Shift+R).

If your HTML files live in a subfolder of the repo (for example /public or /site),
open that folder on GitHub first, then upload.
